# 年会报名签到系统

纯网页实现的年会报名与签到系统，支持 1500 人。单机演示使用浏览器本地存储，预留后端接口便于后期上线。

## 快速开始

### 本地演示（单机）

1. 双击打开 `index.html`，或右键选择「用浏览器打开」
2. 首次进入：首页显示登录表单，输入**花名 + 手机号**登录；登录后记住，下次同浏览器打开无需再登录
3. 首页：4 张卡片（大会信息、会议报名、参会指南、云相册），底部 Tab：首页/签到/我的
4. 报名：点击「会议报名」填写花名、手机号、所属团队、基地、职位后提交
5. 我的：自动按当前登录身份展示状态（未报名/审批中/未通过/审核通过）；审核通过后直接展示邀请函、参会信息、天气提示，可退出登录
6. 签到：点击「签到」页内「签到」按钮，按当前登录身份一键签到，获得顺序编号
7. 管理：首页连续点击主标题 5 次（2 秒内），输入密码（默认 `admin123`）进入 `admin.html`

### 页面说明

| 文件         | 用途                                     |
|--------------|------------------------------------------|
| index.html   | 首页入口，4 卡片 + 底部 Tab              |
| register.html| 会议报名                                 |
| query.html   | 我的，按登录身份展示报名状态与邀请函等       |
| checkin.html | 签到，一键签到获得顺序编号                 |
| info.html    | 大会信息                                 |
| guide.html   | 参会指南                                 |
| admin.html   | 管理员后台（审批、签到管理、天气提示、导出） |

## 管理员后台

- **入口**：首页主标题连续点击 5 次 → 输入密码（默认 `admin123`，可在 `js/config.js` 修改）
- **报名审批**：查看所有报名，点击「通过」或「不通过」
- **签到管理**：仅显示已通过人员，区分已签到/未签到及编号
- **天气提示**：填写内容后，在「我的」页审核通过用户的天气卡片中展示
- **导出**：一键导出 Excel（花名、手机号、所属团队、基地、职位、报名状态、签到状态、签到编号）

## 签到规则

- 编号按签到先后顺序：0001、0002 … 最多 1500
- 一人一码，不可重复签到
- 须先通过审核才能签到

## 上线部署

当前为本地演示版，数据存于浏览器 LocalStorage。

如需上线（链接/二维码分享）：

1. 将 `js/storage.js` 中的 `USE_BACKEND` 改为 `true`
2. 部署后端 API，实现与 `DataService` 相同接口
3. 将前端页面部署到任意静态服务器（如 Nginx、Vercel、GitHub Pages）
4. 分享页面链接或生成二维码供用户访问

## Excel 导出

- 优先使用 SheetJS 从 CDN 加载，导出 `.xlsx`
- 若网络受限，系统会自动降级为 CSV 导出，Excel 可直接打开

若需离线使用 Excel 导出，可下载 SheetJS 脚本到 `js/vendor/xlsx.full.min.js`，并在 `admin.html` 中改为引用本地文件。

## 技术说明

- 前端：HTML5 + CSS + 原生 JavaScript
- 数据：LocalStorage（演示）/ 预留后端 API 切换
- Excel：SheetJS Community 版
