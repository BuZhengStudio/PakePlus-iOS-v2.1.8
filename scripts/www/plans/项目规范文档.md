# 年会报名签到系统 — 项目规范文档

## 一、项目概述

| 项目 | 说明 |
|------|------|
| 实现方式 | 纯网页（HTML + CSS + JS） |
| 适用终端 | 手机浏览器、电脑浏览器 |
| 人数上限 | 1500 人 |
| 数据模式 | 单机演示：LocalStorage；上线：后端 API（已预留） |

---

## 二、用户端功能

### 2.1 登录与记住登录（方案 A）
- 首次打开链接/扫码：首页展示登录表单，花名 + 手机号登录
- 登录成功后写入 LocalStorage，下次同设备打开无需再登录
- 报名、签到、我的 须已登录方可使用；未登录访问会跳转首页

### 2.2 报名
- 字段：花名、手机号（必填），所属团队（选填），基地（下拉），职位（下拉）
- 基地选项：杭州/扬州/沈阳/徐州/西安/洛阳/郑州/济南/合肥/安吉/邳州/青岛/其他
- 职位选项：主持、厅管、多厅、运营、中台、其他
- 提交后提示：报名成功，等待审核

### 2.3 我的
- 无需输入手机号，按当前登录身份自动拉取报名状态
- 展示：未报名 / 审批中 / 抱歉您未通过本次年会报名 / 审核通过（邀请函 + 参会信息 + 天气）
- 审核通过后直接展示邀请函，可退出登录

### 2.4 签到
- 无需输入手机号，使用当前登录身份一键签到
- 规则：须已通过审核、一人一码、按顺序编号 0001～1500
- 签到成功后：展示编号 + 花名

## 三、管理员后台

| 功能 | 说明 |
|------|------|
| 入口 | 首页主标题连续点击 5 次（2 秒内）→ 密码弹窗（默认 `admin123`） |
| 报名审批 | 列表展示，通过 / 不通过 |
| 签到管理 | 仅显示已通过人员，已签到 / 未签到 + 编号 |
| 天气提示 | 编辑后在「我的」页展示 |
| 导出 | Excel：花名、手机号、所属团队、基地、职位、报名状态、签到状态、签到编号 |

---

## 四、页面与导航

### 4.1 页面结构

| 文件 | 用途 |
|------|------|
| index.html | 首页入口 |
| register.html | 会议报名 |
| query.html | 我的（查询 + 邀请函等） |
| checkin.html | 签到 |
| info.html | 大会信息 |
| guide.html | 参会指南 |
| admin.html | 管理员后台 |

### 4.2 底部 Tab
首页 / 签到 / 我的（`index.html`、`checkin.html`、`query.html`、`register.html` 等共用）

### 4.3 首页布局
- 未登录：展示登录表单（花名、手机号）；登录后展示 4 卡片
- 已登录：顶部主标题「以热爱 赴未来」、副标题「2025年度盛典」；中部 4 卡片（大会信息、会议报名、参会指南、云相册）；云相册点击「敬请期待」

## 五、配置与数据

### 5.1 配置 `js/config.js`
- `title`：主标题
- `subtitle`：副标题
- `adminPassword`：管理员密码
- `invitationThanks`、`invitationDesc`：邀请函文案
- `schedule`：参会信息日程

### 5.2 登录态 `js/auth.js`
- `getLoginUser()`、`setLoginUser(name, phone)`、`clearLoginUser()`
- 存储 key：`annual_meeting_login`

### 5.3 数据接口 `storage.js`
- `submitRegistration`、`getRegistration`、`submitCheckin`
- `adminGetAll`、`adminApprove`、`adminExport`
- `getWeatherTip`、`setWeatherTip`
- 开关：`USE_BACKEND = false`（改为 `true` 对接后端）
